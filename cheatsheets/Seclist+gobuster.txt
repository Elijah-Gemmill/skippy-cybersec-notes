1. GOBUSTER
------------------------------------------------------------

Basic syntax:
gobuster dir [OPTIONS]

Arguments:

-u URL             Target URL
-w WORDLIST        Specify wordlist
-o FILE            Save results to file
-t NUMBER          Number of concurrent threads
-x EXTENSIONS      Specify file extensions
-s CODES           Include status codes
-b CODES           Exclude status codes
-k                 Skip TLS certificate verification
-r                 Follow redirects
-q                 Quiet output
-v                 Verbose output
-h                 Display help

Basic uses:

-u  = Specify the authorized target
-w  = Select a wordlist
-o  = Save scan output
-t  = Adjust concurrency
-x  = Check specified file extensions
-s  = Filter HTTP status codes
-b  = Exclude unwanted status codes
-k  = Allow self-signed certificates
-r  = Follow redirects
-q  = Reduce terminal output
-v  = Display additional information
-h  = Show available arguments


2. DIRB
------------------------------------------------------------

Basic syntax:
dirb URL [WORDLIST] [OPTIONS]

Arguments:

-a USER_AGENT      Set User-Agent
-c COOKIE          Set HTTP cookie
-H HEADER          Add HTTP header
-o FILE            Save output
-S                 Silent mode
-v                 Verbose mode
-w                 Do not stop on warnings
-z MILLISECONDS    Set request delay
-N CODE            Ignore HTTP response code
-X EXTENSION       Append extension
-p PROXY           Use HTTP proxy
-r                 Do not search recursively
-h                 Display help

Basic uses:

-a  = Change User-Agent
-c  = Send cookies
-H  = Add custom HTTP headers
-o  = Save scan results
-S  = Reduce output
-v  = Show additional details
-w  = Continue despite warnings
-z  = Control request delay
-N  = Ignore a response code
-X  = Check a specific extension
-p  = Route through a proxy
-r  = Disable recursive scanning
-h  = Show help


3. DIRBUSTER
------------------------------------------------------------

Basic syntax:
DirBuster

Common interface settings:

Target URL          Specify authorized target
Threads             Configure concurrent requests
File with list      Select wordlist
File extension      Specify extensions
Start              Begin discovery
Stop                Stop discovery
Report              View scan report

Basic uses:

Target URL          = Define target
Threads             = Adjust concurrency
File with list      = Select dictionary
File extension      = Check additional extensions
Start               = Begin directory discovery
Stop                = Stop current scan
Report              = Review discovered resources

Official documentation:
https://www.kali.org/tools/dirbuster/


4. FFUF
------------------------------------------------------------

Basic syntax:
ffuf [OPTIONS]

Arguments:

-u URL              Target URL
-w WORDLIST         Specify wordlist
-o FILE             Save results
-of FORMAT          Output format
-t NUMBER           Number of threads
-mc CODES           Match status codes
-fc CODES           Filter status codes
-fs SIZE            Filter response size
-fl LINES           Filter line count
-fw WORDS           Filter word count
-H HEADER           Add HTTP header
-X METHOD           HTTP method
-rate NUMBER        Requests per second
-h                  Display help

Basic uses:

-u  = Specify target URL
-w  = Load wordlist
-o  = Save results
-of = Select output format
-t  = Adjust concurrency
-mc = Match response codes
-fc = Exclude response codes
-fs = Filter response sizes
-fl = Filter line counts
-fw = Filter word counts
-H  = Add custom headers
-X  = Specify HTTP method
-rate = Limit request rate
-h  = Display help

Official documentation:
https://github.com/ffuf/ffuf


5. WFUZZ
------------------------------------------------------------

Basic syntax:
wfuzz [OPTIONS] URL

Arguments:

-w FILE             Specify wordlist
-H HEADER           Add HTTP header
-c                  Enable colored output
-t NUMBER           Number of threads
--hc CODE           Hide response codes
--sc CODE           Show response codes
--hl NUMBER         Hide line counts
--hw NUMBER         Hide word counts
--hh NUMBER         Hide character counts
--ss TEXT           Search response text
-h                  Display help

Basic uses:

-w  = Select wordlist
-H  = Add HTTP header
-c  = Enable colored output
-t  = Configure concurrency
--hc = Hide specified response codes
--sc = Show specified response codes
--hl = Filter by line count
--hw = Filter by word count
--hh = Filter by character count
--ss = Search for response text
-h  = Display help

Official documentation:
https://github.com/xmendez/wfuzz


6. CURL – HTTP TESTING
------------------------------------------------------------

Basic syntax:
curl [OPTIONS] URL

Arguments:

-I                  Show response headers
-i                  Include response headers
-v                  Verbose output
-s                  Silent mode
-L                  Follow redirects
-k                  Skip TLS verification
-o FILE             Save response to file
-H HEADER           Add HTTP header
-X METHOD           Specify HTTP method
-d DATA             Send request data
-A USER_AGENT       Set User-Agent
-b COOKIE           Send cookies
-h                  Display help

Basic uses:

-I  = Inspect HTTP headers
-i  = Display headers and body
-v  = Show connection details
-s  = Suppress progress output
-L  = Follow redirects
-k  = Ignore certificate validation
-o  = Save response
-H  = Add custom headers
-X  = Set request method
-d  = Send request data
-A  = Change User-Agent
-b  = Send cookies
-h  = Show help

3. GOBUSTER COMMANDS
--------------------

SMALL WORDLIST:(use mainly)
gobuster dir -u http:/IP Address -w /usr/share/dirbuster/wordlists/directory-list-2.3-small.txt f

MEDIUM WORDLIST:
gobuster dir -u http://IP Address -w /usr/share/dirbuster/wordlists/directory-list-2.3-medium.txt

BIG WORDLIST:
gobuster dir -u http://IP Address -w /usr/share/dirbuster/wordlists/directory-list-2.3-big.txt


4. SEARCH FOR SPECIFIC FILE EXTENSIONS
--------------------------------------

Use -x to specify file extensions.

Example:
gobuster dir -u http://10.129.218.213 -w /usr/share/dirbuster/wordlists/directory-list-2.3-medium.txt -x php,txt,html
